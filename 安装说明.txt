网页万能遥控 · Edge / Chrome 扩展
================================

这是一个 Chromium（Manifest V3）扩展，在 Microsoft Edge 和 Google Chrome 上同样可用。
打开网页后左下角会出现可拖拽的浮层遥控器。不支持 Firefox、Safari。

能做什么
--------
- 快退 1 分钟 / 快退 10 秒 / 播放暂停 / 快进 10 秒 / 快进 1 分钟
- 上一页、下一页（优先点站内「上一页 / 下一集 / 下一章」这类按钮）
- 点成功但点错了：可「尝试其他可能按键」或「改为指定某按键」
- 点按钮后立刻显示「正在尝试」，完成后再显示结果
- 高级：音视频倍速、CSS 动画、自动下一页、指定按钮、遥控器大小

部分页面结构比较特殊，扩展会走单独的适配（场景特化）。
目前已完成课件类页面，以后可能再增加。细节见「特化说明.md」。

怎么判断点的是页面按钮
----------------------
- 绿色圆点：识别到了页面上的对应按钮，会模拟真实点击
- 蓝色圆点：没找到按钮，但页面里有音视频，会直接控制播放器（改进度 / 播放暂停）
- 没有圆点：会提示未找到。连点遥控按钮不会强制。只有提示里的「强制执行」才会强制

点成功但不是我想要的按钮
------------------------
提示不会立刻消失。可以：
- 「尝试其他可能按键」：跳过刚才那个，改点下一个候选
- 「改为指定某按键」：你自己点一次页面上的正确按钮，以后优先用它
  指定后如果网页跳转了，新页面仍会弹出「已记住」，可再次改指定
  高级里也可随时点「指定上一页 / 下一页 / 播放」
  不能指定遥控器自己的按钮；点完会提示指定成功或失败
  「删除本网站所有指定」会清掉当前网站记下的全部按钮

强制执行（有风险，请谨慎）
--------------------------
使用强制跳过可能存在风险，请谨慎使用。
强制翻页会绕过网站原来的点击与校验逻辑，页面看起来翻过去了，
站点自己的状态或数据可能没有同步更新。
日常请让遥控去点页面上的原按钮。

高级
----
点遥控器上的「高级」展开：
- 音视频倍速：0.5× / 1× / 2× / 16×（作用于当前识别到的音视频）
- CSS 动画：加速或跳到结束，只对 CSS / Web Animations 有效。
  「持续检查」打开后每 0.1 秒再套用一次上次点的倍速或跳过。
  不管视频、脚本逐帧动画、Canvas。跳过可能让依赖动画结束的页面状态对不上。
- 自动下一页：按间隔重复执行普通「下一页」（不会强制执行）
  预设间隔：50ms、500ms、1s、10s、1min
  也可输入 10–600000 毫秒的整数
  找不到按钮时会自动停止。间隔过短可能连点过快，请自行斟酌。
- 指定按钮：指定上一页 / 下一页 / 播放，或删除本网站所有指定
- 遥控器大小：75% / 90% / 100% / 115% / 130%，避免挡住画面或看不清

安装（Edge）
------------
1. 打开 edge://extensions/
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」，选中本文件夹「网页万能遥控」
4. 打开扩展详细信息，把「网站访问」设为「在所有网站上」
5. 打开任意网页，或用浏览器打开同目录下的 demo.html
6. 若遥控器挡住画面：可拖标题栏，点「–」最小化，点「×」隐藏
7. 隐藏后，再点工具栏里的扩展图标即可重新显示

安装（Chrome）
--------------
与 Edge 功能相同，只是入口名字不同：
1. 打开 chrome://extensions/
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选中本文件夹「网页万能遥控」
4. 打开扩展「详细信息」：
   - 「网站访问」选「在所有网站上」（On all sites）
   - 如需无痕窗口，勾选「在无痕模式下启用」
   - 如需打开本地 demo.html，勾选「允许访问文件网址」
5. 其余用法与 Edge 相同

如果工具栏没有图标
------------------
Edge：edge://extensions/ → 详细信息 → 在工具栏中显示
Chrome：扩展图标拼图 → 钉住「网页万能遥控」

哪些页面本来就出不来
--------------------
浏览器禁止扩展注入的页面打不开遥控器，这是系统限制：
- edge://、chrome://、设置、扩展管理、新标签页
- Edge 扩展商店、Chrome 网上应用店
- 内置 PDF 阅读器
- IE 模式页面（仅 Edge）
- 未授权的 file:// 本地文件
- 未允许扩展运行的 InPrivate / 无痕窗口

另外：加载扩展之前就已经打开的标签页，需要刷新一次，或点一下工具栏图标。
若曾点过遥控器上的 ×，所有网站都会记住「已隐藏」，再点工具栏图标即可显示。
图标上出现红色「!」表示当前页无法注入。

用 file:// 打开 demo.html 时
----------------------------
扩展详情里打开「允许访问文件网址」，然后刷新页面。

常见站点
--------
YouTube、B 站、爱奇艺、优酷、腾讯视频、Netflix 等会优先点播放器自带按钮。
有的站点没有 10 秒 / 1 分钟按钮，这时只要识别到播放器就会直接改进度，不用二次确认。
