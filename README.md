# 网页万能遥控

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

网页万能遥控器：支持 Edge / Chrome 的浏览器扩展，实现音视频、动画等快进暂停，各类型翻页以及自动化脚本，遵循模拟原有交互优先原则，并对某些场景进行了特化。当前版本 **1.5.0**。

Webpage Universal Remote: a browser extension for Microsoft Edge and Chrome. It can seek and pause audio, video, and animations, handle various kinds of in-page navigation, and run automation. It prefers simulating the site's own interactions first, and includes specialized handling for certain scenarios.

> [!WARNING]
> **使用某些功能可能存在风险，请谨慎使用。**
>
> 本扩展会操作页面按钮、播放器和动画时间轴，不保证在所有网站上都安全、正确。站点若校验进度、计时、必做步骤或交互动画，部分功能可能导致页面状态与后台数据不一致，或其他异常。
>
> 请优先让遥控去点页面原来的按钮。强制翻页、过快的自动下一页等尤其需要自行判断。作者与贡献者不对误用造成的后果负责。

## 功能

- 优先模拟页面原有交互，而不是绕过站点逻辑  
- **CSS / Web Animations 加速与跳过**（含持续检查，新出现的动画也会套用）  
- 音视频快进、暂停、倍速；站内上一页 / 下一页  
- 自动下一页；对课件等场景有特化处理  

细节与课件适配见 [特化说明.md](./特化说明.md)。

## 安装（未上架，加载未打包扩展）

Chrome 与 Edge 步骤相同，只是扩展页地址不同。

1. 克隆本仓库，或下载 ZIP 并解压  
2. 打开扩展页：Edge 为 `edge://extensions/`，Chrome 为 `chrome://extensions/`  
3. 打开「开发人员模式」（Chrome 在页面右上角，Edge 在左下角）  
4. 「加载解压缩的扩展」，选中本仓库根目录  
5. 打开扩展**详细信息**，将「网站访问」设为 **在所有网站上**（Chrome：Site access → On all sites）  
   - 若只允许「单击时」，跨域 iframe 里的内容无法操作  
6. 打开任意网页，左下角应出现「万能遥控」  

用 `file://` 打开 `demo.html` 时，请在扩展详情中允许访问文件网址。  
Chrome 无痕 / Edge InPrivate 需在详情里单独勾选允许。不支持 Firefox、Safari。更细的对照见 [安装说明.txt](./安装说明.txt)。

## 使用

面板上能看懂的操作不再重复。下面这些容易忽略：

- 隐藏后，点浏览器工具栏里的扩展图标可再显示  
- 「网站访问」必须是**在所有网站上**，跨域 iframe（含部分课件）才能控到  
- 点错了：提示里可「尝试其他可能按键」，或「改为指定某按键」点一次页面上的正确按钮；不能指定遥控器自己  
- 「强制执行」只会从提示条的红按钮触发，连点「下一页」不会强制  
- 自动下一页 / CSS 持续检查开启时，顶部信息栏会变黄并有扫光，便于确认还在跑  

## 操作安全性评估

星级越高，相对越不容易把站点自己的校验弄乱。**不是**「可以随便用」。同一类操作在不同网站上的后果差很多，下表只是经验判断。

| 操作 | 安全星级 | 说明 |
|---|---|---|
| 音视频快进 / 倍速 | ★★☆☆☆ | 直接改播放器进度或 `playbackRate`。很多学习站、会员站会在后台核对「是否真的看到了某一秒」。快进或 16 倍速后，页面看起来正常，进度、心跳或防挂机检测可能对不上，轻则不计完成，重则被判定异常。 |
| 上一页 / 下一页 | ★★★☆☆ | 默认去点页面上已有的翻页 / 下一集按钮，走站点原来的点击逻辑，比改 DOM 安全。但仍可能点到「下一篇推荐」而不是「下一节」，或在未完成必看/必答时被允许翻页。画面变了可以自己看一眼再决定要不要改指定。 |
| 强制翻页 | ★☆☆☆☆ | **不会**点击原按钮，只改页面结构或当前页标记。校验、计数、接口回调、解锁条件都会被跳过，后台很容易和画面不一致。只建议你明确知道后果时使用（例如本地测试）。 |
| 自动下一页 | ★★☆☆☆ | 按设定间隔反复执行普通「下一页」，不会走强制。间隔很短时，必看视频、题目、确认框还没来得及出现就被翻走，人也来不及核对点没点错。间隔请尽量留出检查时间。 |
| CSS 动画倍速 / 跳过 | ★★★★☆ | 只动 CSS / Web Animations 的时间轴，不管视频和脚本逐帧。多数站点不会在后台核对这类过场动画是否播完，一般不易出错。若某页靠动画结束才解锁按钮或提交状态，跳过仍可能提前进入下一步。无限循环的 loading 默认不会被「跳过」掐掉。 |

## 权限说明

- `<all_urls>`：在网页上显示遥控并操作按钮 / 播放器 / 动画  
- `storage`：记住位置、大小与是否隐藏  
- `webNavigation` / `scripting`：在子 frame 中查找并执行操作  

不会上传你的账号密码。遥控触发的请求仍由**该网站**发出，请自行遵守网站使用条款。
